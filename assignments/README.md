# 作业区

负责人先通过 [作业发布表单](https://github.com/wzm-Epoch/zhaogege/issues/new/choose) 发布任务，并指定唯一的作业编号，再按需创建 `作业编号/README.md` 保存详细要求。

成员在 `作业编号/GitHub用户名/` 下提交，并在该目录提供 `README.md`。同一份作业的所有附件均放在自己的目录中。

目录示例（不是实际任务）：

```text
assignments/
  task-001/
    README.md
    octocat/
      README.md
      solution.py
      result.png
```

提交步骤见 [成员提交指南](../CONTRIBUTING.md)，内容格式见 [作业模板](../templates/homework.md)。目前没有在本次优化中创建任何真实作业、截止时间或评分规则。
