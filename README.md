# zhaogege · 成员作业与学习交流

这里用于发布学习任务、提交成员作业、记录每周分享，以及交流学习中遇到的问题。

## 从这里开始

- **找作业**：到 [Issues](https://github.com/wzm-Epoch/zhaogege/issues) 查看标题以 `[作业发布]` 开头的任务。
- **交作业**：先读 [提交指南](CONTRIBUTING.md)，复制 [作业模板](templates/homework.md)，通过 Pull Request（PR，合并申请）提交。
- **提问题 / 分享资源**：从 [交流入口](https://github.com/wzm-Epoch/zhaogege/issues/new/choose) 选择对应表单。
- **写周总结**：查看 [每周分享总结](ai-learning-notes/每周分享总结/README.md) 和 [周总结模板](templates/weekly-summary.md)。
- **管理任务与审核**：查看 [负责人指南](docs/maintainer-guide.md)。

## 内容放在哪里

```text
assignments/                         作业说明与成员提交
  <作业编号>/README.md              负责人补充的任务说明
  <作业编号>/<GitHub用户名>/README.md 个人作业说明及相关文件
ai-learning-notes/                   学习笔记
  每周分享总结/<YYYY-MM-DD>/<GitHub用户名>.md
templates/                          可复制的内容模板
docs/                               使用和维护说明
```

作业编号由负责人发布任务时给出；上面的尖括号是示意，创建文件时换成实际内容。

## 协作约定

1. 一个 PR 对应一份作业或一个主题；修改自己的目录，避免覆盖他人的内容。
2. 负责人检查后合并；需要修改时，在原 PR 的分支继续更新。
3. 提问说明背景、已尝试的方法和具体问题；引用资料注明来源。
4. 本仓库公开可见。使用 GitHub 用户名即可，不提交密码、密钥、学号、手机号等私人信息。
5. 截止时间、评分方式、作业要求以负责人发布的具体任务为准。

自动检查只检查文档链接和提交目录等基础规范，不评价作业内容，也不执行成员作业。
