# 每周分享总结

记录每周学习内容、实践结果、问题与下一步计划。

1. 复制 [周总结模板](../../templates/weekly-summary.md)。
2. 按分享日期创建 `YYYY-MM-DD/GitHub用户名.md`，例如 `2026-10-30/octocat.md`（仅示例）。
3. 按 [提交指南](../../CONTRIBUTING.md) 发起 PR，在正文关联相关作业或讨论。

每位成员使用独立文件，无需多人同时修改本页维护索引；通过日期目录即可浏览。

原有 `2026.10.28` 是空白占位文件，本次保留，没有补写未经确认的历史记录。后续新记录统一使用上述 Markdown 文件格式。
