# 关于项目

zhaogege 用于成员提交作业、交流学习问题、分享资料和积累学习总结。

## 使用方式

- 任务发布、提问和资源讨论使用 [Issues](https://github.com/wzm-Epoch/zhaogege/issues)。
- 作业和学习笔记通过 PR 提交，由负责人检查后合并。
- 成员使用自己的 GitHub 用户名组织文件，避免修改他人的提交。

具体步骤见 [成员提交指南](../CONTRIBUTING.md)。作业要求、时间安排和评分方式由负责人在各任务中说明。

## 公开内容

本仓库公开可见，适合存放可公开的学习材料和个人实践记录。提交前检查内容的公开权限，引用他人材料时保留来源；未经授权的教材、私人信息和访问凭据不应上传。
